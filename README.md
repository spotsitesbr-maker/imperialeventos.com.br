# Imperial Eventos — Microsite de Alta Performance

Microsite estático oficial da **Imperial Eventos** (Casa de Festas, Salão Nobre e Buffet em Manaus / Vieiralves).

## 🏛️ Sobre o Projeto
Convertido e redesenhado a partir do WordPress/Elementor anterior para uma arquitetura estática pura, ultra-rápida, com visual cinematográfico contemporâneo e foco em conversão direta para o WhatsApp.

- **Conceito Visual:** Cinematic Gala & Vídeo Ambient (Dark Glass / Minimalismo Nobre).
- **Estrutura:** Salão 100% Climatizado, Lustres de Cristal, Mobiliário e Enxoval Completo, Gastronomia de Buffet e Decoração Exclusiva.
- **Capacidade:** 80 a 250 convidados.
- **Localização:** Vieiralves / Nossa Senhora das Graças, Manaus - AM.
- **Fundação:** 2009 (Lilian Manoela Fernandes de Melo & Jonathan Magalhães).
- **CNPJ:** 26.508.542/0001-63.

## 🚀 Tecnologias
- HTML5 Semântico com Schema.org `EventVenue` (SEO Local Manaus)
- CSS3 Moderno (Glassmorphism, Flexbox, CSS Grid, Ambient Video Background)
- JavaScript Vanilla (Filtros interativos da galeria e simulador de orçamento para WhatsApp)
- Pronto para deploy no **Cloudflare Pages / Workers** ou qualquer CDN estática

## 📂 Arquivos
- `index.html`: Microsite oficial de produção
- `previews/`: Versões de estudo e conceitos alternativos
